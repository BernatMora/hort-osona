<h2 id="2-apps-dx27identificació-de-plantes">2. Apps d&#x27;identificació de plantes</h2>
<h3 id="a-plantnet-la-millor">A. PlantNet (⭐⭐⭐⭐⭐ — LA MILLOR)</h3>
<p><strong>Què fa</strong>: identifica plantes a partir d&#x27;una foto.</p>
<p><strong>Tipus d&#x27;identificació</strong>:</p>
<ul>
<li>Flors</li>
<li>Fulles</li>
<li>Fruits</li>
<li>Escorces</li>
<li>Hàbits (com creix la planta)</li>
</ul>
<p><strong>Bases de dades</strong>:</p>
<ul>
<li>Més de 20.000 espècies</li>
<li>Inclou plantes europees i catalanes</li>
<li><strong>Funciona offline</strong> (descarregar paquet)</li>
</ul>
<p><strong>Com fer-la servir</strong>:</p>
<ol>
<li>Descarregar l&#x27;app (gratuïta)</li>
<li>Fer una foto de la planta</li>
<li>Triar el tipus (flor, fulla, etc.)</li>
<li>L&#x27;app et dona possibles identificacions</li>
<li>Confirmar o refutar</li>
</ol>
<p><strong>Útil per a</strong>:</p>
<ul>
<li>Identificar adventícies</li>
<li>Reconèixer plantes remeieres</li>
<li>Saber si una planta és comestible o tòxica</li>
<li>Aprendre noms científics</li>
</ul>
<p><strong>Disponible</strong>: iOS, Android</p>
<p><strong>Preu</strong>: gratuïta</p>
<p><strong>Idioma</strong>: català, espanyol, anglès, francès</p>
<p><strong>URL</strong>: https://plantnet.org</p>
<h3 id="b-inaturalist-">B. iNaturalist (⭐⭐⭐⭐)</h3>
<p><strong>Què fa</strong>: identificació + comunitat científica ciutadana.</p>
<p><strong>Avantatges</strong>:</p>
<ul>
<li>Identificació automàtica</li>
<li>Validació per experts</li>
<li>Comunitat activa</li>
<li>Dades obertes (útil per a ciència)</li>
</ul>
<p><strong>Com fer-la servir</strong>:</p>
<ol>
<li>Descarregar l&#x27;app</li>
<li>Fer foto + geolocalització</li>
<li>L&#x27;app proposa identificacions</li>
<li>La comunitat valida</li>
<li>Acumules &quot;graus&quot; de naturalista</li>
</ol>
<p><strong>Útil per a</strong>:</p>
<ul>
<li>Aprendre a identificar</li>
<li>Contribuir a la ciència</li>
<li>Trobar altres naturalistes a la teva zona</li>
</ul>
<p><strong>Disponible</strong>: iOS, Android</p>
<p><strong>Preu</strong>: gratuïta</p>
<p><strong>Idioma</strong>: anglès (interfície), espanyol (comunitat)</p>
<p><strong>URL</strong>: https://www.inaturalist.org</p>

<h2 id="17-què-no-fer-amb-les-eines-digitals">17. Què NO fer amb les eines digitals</h2>
<h3 id="a-errors-comuns">A. Errors comuns</h3>
<ol>
<li><strong>Dependència excessiva</strong>: no tot es pot fer amb una app!</li>
<li><strong>Desconeixement real</strong>: l&#x27;app no substitueix l&#x27;observació directa</li>
<li><strong>Privacitat</strong>: moltes apps venen les teves dades</li>
<li><strong>Distracció</strong>: estar mirant el mòbil a l&#x27;hort</li>
<li><strong>Ansietat per les dades</strong>: no cal mesurar-ho tot</li>
</ol>
<h3 id="b-mantenir-lx27equilibri">B. Mantenir l&#x27;equilibri</h3>
<ul>
<li><strong>Usa la tecnologia</strong> com a eina, no com a mestre</li>
<li><strong>Confia en l&#x27;observació</strong> directa</li>
<li><strong>Toca la terra</strong>, olorar les plantes, escoltar els ocells</li>
<li><strong>L&#x27;hort és connexió amb la natura</strong>, no amb la pantalla</li>
</ul>
