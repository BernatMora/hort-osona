<h1 id="-guia-dx27anàlisi-de-rendiment-de-lx27hort-quant-produeixes-">📊 Guia d&#x27;Anàlisi de Rendiment de l&#x27;Hort — Quant produeixes, quant estalvies, quant vius</h1>
<blockquote>Cada cop que <strong>talles un enciam, culls un tomàquet, o arrenques una ceba</strong> del teu hort, estàs <strong>produint aliment</strong> amb les teves pròpies mans. Però... <strong>saps quant produeixes realment</strong>? <strong>Quant estalvies</strong>? <strong>Quant val la teva feina</strong>? <strong>Quin és el retorn</strong> de les hores, l&#x27;aigua, els diners invertits? Aquesta guia t&#x27;ensenya a <strong>calcular, mesurar, analitzar, i optimitzar</strong> el <strong>rendiment del teu hort</strong> de 20 m² a Osona. Amb <strong>dades reals</strong>, <strong>fórmules concretes</strong>, <strong>taules comparatives</strong>, i <strong>consells pràctics</strong> per <strong>augmentar la productivitat</strong>, <strong>reduir costos</strong>, i <strong>gaudir més</strong> del teu hort.</blockquote>

<h3 id="43-retorn-de-la-inversió-roi">4.3. Retorn de la inversió (ROI)</h3>
<p><strong>ROI</strong> = (Estalvi - Costos) / Costos × 100</p>
<p><strong>Any 1</strong> (amb inversió inicial):</p>
<ul>
<li>Costos totals: 300-625 € (inversió + anuals)</li>
<li>Estalvi: 305 €</li>
<li><strong>ROI negatiu</strong> el primer any</li>
</ul>
<p><strong>A partir de l&#x27;any 2</strong> (només costos anuals):</p>
<ul>
<li>Costos: 125-295 €</li>
<li>Estalvi: 305 €</li>
<li><strong>ROI positiu</strong>: 3-144%</li>
</ul>
<p><strong>Any 3+</strong> (consolidació):</p>
<ul>
<li>Costos: 125-295 €</li>
<li>Estalvi: 350-500 € (amb millores)</li>
<li><strong>ROI positiu</strong>: 18-300%</li>
</ul>
<h3 id="44-cost-per-kg-produït">4.4. Cost per kg produït</h3>
<p><strong>Cost per kg</strong> = Costos totals / Kg totals</p>
<p><strong>Any 1</strong>: 625 € / 113 kg = 5,53 €/kg</p>
<p><strong>Any 2+</strong>: 200 € / 113 kg = 1,77 €/kg</p>
<p><strong>Comparat amb mercat (mitjana 2,80 €/kg)</strong>:</p>
<ul>
<li>Any 1: NO és rendible (per la inversió)</li>

</ul>

<h2 id="7-millorar-el-rendiment">7. MILLORAR EL RENDIMENT</h2>
<h3 id="71-com-augmentar-la-producció-30-50">7.1. Com AUGMENTAR la producció (+30-50%)</h3>
<p><strong>TÈCNIQUES</strong>:</p>
<ol>
<li><strong>Mulching</strong> (millora el sòl, estalvia aigua)</li>
<li><strong>Rotació de cultius</strong> (evita plagues)</li>
<li><strong>Associacions</strong> (pastanaga + ceba, tomàquet + alfàbrega)</li>
<li><strong>Reg eficient</strong> (degoteig, al matí o al vespre)</li>
<li><strong>Fertilització ecològica</strong> (compost, fem, adobs verds)</li>
<li><strong>Varietats productives</strong> (adaptades a la zona)</li>
<li><strong>Plantació escalonada</strong> (enciam cada 2-3 setmanes)</li>
<li><strong>Tutors</strong> (tomàquets, pebrots, mongetes)</li>
<li><strong>Protecció</strong> (malla, hivernacle, ventall)</li>
<li><strong>Poda</strong> (treure xucladors, fulles velles)</li>
</ol>
<h3 id="72-com-reduir-els-costos--30-50">7.2. Com REDUIR els costos (-30-50%)</h3>
<p><strong>ESTRATÈGIES</strong>:</p>
<ol>
<li><strong>Guardar llavors</strong> (estalvia 30-50 € l&#x27;any)</li>
<li><strong>Fer planter</strong> (estalvia 30-60 € l&#x27;any)</li>
<li><strong>Fer compost</strong> (estalvia 20-50 € l&#x27;any)</li>
<li><strong>Aprofitament d&#x27;aigua</strong> (bidons, pluja)</li>
<li><strong>Reutilitzar</strong> materials (pals, tests)</li>
<li><strong>Compartir</strong> eines amb veïns</li>
<li><strong>Mulching casolà</strong> (palla, gespa, fulles)</li>
<li><strong>Tractaments naturals</strong> (no comprar pesticides)</li>
</ol>
<h3 id="73-com-millorar-la-qualitat">7.3. Com MILLORAR la qualitat</h3>
<ul>
<li>Triar <strong>varietats locals</strong> (sabors, adaptació)</li>
<li><strong>Collir al punt òptim</strong> (no massa verd, no massa madur)</li>
<li><strong>Conservar</strong> correctament (fredor, humitat)</li>
<li><strong>Transformar</strong> els excedents (conserves, olis, etc.)</li>
<li><strong>Etiquetar</strong> (data, varietat, origen)</li>
</ul>
<h2 id="8-exercicis-pràctics">8. EXERCICIS PRÀCTICS</h2>
<h3 id="81-càlcul-del-teu-hort">8.1. Càlcul del teu hort</h3>
<p><strong>PASSOS</strong>:</p>
<ol>
<li><strong>Crea</strong> una llibreta o full de càlcul</li>
<li><strong>Anota</strong> cada sembra/trasplantament</li>
<li><strong>Anota</strong> cada collita (data, quantitat)</li>
<li><strong>Anota</strong> cada despesa</li>
<li><strong>Anota</strong> cada hora dedicada</li>
</ol>
<p><strong>AL FINAL DE LA TEMPORADA</strong>:</p>
<ul>
<li>Suma kg collits</li>
<li>Suma costos</li>
<li>Suma hores</li>
<li>Calcula estalvi</li>
<li>Compara amb anys anteriors</li>
</ul>
<h3 id="82-comparació-amb-el-mercat">8.2. Comparació amb el mercat</h3>
<p><strong>PASSOS</strong>:</p>
<ol>
<li>Compara el teu <strong>preu per kg</strong> amb el del mercat</li>
<li>Compara la <strong>qualitat</strong> (gust, frescor)</li>
<li>Compara la <strong>distància</strong> (0 vs 50-500 km)</li>
<li>Compara el <strong>packaging</strong> (paper vs plàstic)</li>
<li>Decideix si el teu hort <strong>és rendible</strong></li>
</ol>
<h3 id="83-producció-esperada-vs-real">8.3. Producció esperada vs real</h3>
<p><strong>CALCULAR</strong>:</p>
<ul>
<li><strong>Producció esperada</strong> (segons les taules)</li>
<li><strong>Producció real</strong> (la que has collit)</li>
<li><strong>Rendiment</strong> = Real / Esperat × 100</li>
<li><strong>&gt;100%</strong>: molt bé!</li>
<li><strong>80-100%</strong>: rendiment correcte</li>
<li><strong>&lt;80%</strong>: cal millorar</li>
</ul>
