<h1 id="-manual-de-decoració-amb-elements-naturals-crear-art-amb-el-">🎨 Manual de Decoració amb Elements Naturals — Crear art amb el que la natura t&#x27;ofereix</h1>
<blockquote>La <strong>decoració amb elements naturals</strong> és una <strong>art ancestral</strong> que connecta la <strong>casa amb el bosc, l&#x27;hort amb la llar, les estacions amb l&#x27;estètica</strong>. Amb <strong>branques, pedres, fulles, flors, pinyes, llavors, closques, i molts altres elements</strong> que tens al teu <strong>hort, jardí, o bosc</strong>, pots crear <strong>centres de taula, garlandes, corones, murals, mòbils, espelmes, i molt més</strong>. Tots <strong>gratis, ecològics, biodegradables, únics</strong>, i plens d&#x27;<strong>ànima</strong>. Aquest manual t&#x27;ensenya <strong>30 projectes</strong> pas a pas, organitzats per estació, amb <strong>materials, eines, tècniques, i consells</strong>.</blockquote>
<h2 id="1-introducció">1. INTRODUCCIÓ</h2>
<h3 id="11-per-què-decorar-amb-elements-naturals">1.1. Per què decorar amb elements naturals?</h3>
<p><strong>AVANTATGES ESTÈTICS</strong>:</p>
<ul>
<li>Materials <strong>únics, irrepetibles</strong></li>
<li><strong>Textures, colors, olors</strong> que no es troben a les botigues</li>
<li><strong>Connexió amb la natura</strong> dins de casa</li>
<li><strong>Estètica única</strong> (rústic, elegant, minimalista, bohemi)</li>
<li><strong>Canviant</strong> amb les estacions</li>
</ul>
<p><strong>AVANTATGES ECOLÒGICS</strong>:</p>
<ul>
<li><strong>Gratis</strong> (només recollir del bosc, hort, jardí)</li>
<li><strong>Biodegradables</strong> (al final, tornen a la terra)</li>
<li><strong>Zero plàstic, zero residus</strong></li>
<li><strong>Zero emissions</strong> de transport</li>
<li><strong>Km 0</strong></li>
</ul>
<p><strong>AVANTATGES PERSONALS</strong>:</p>
<ul>
<li><strong>Activitat relaxant</strong> (mena mindfulness)</li>
<li><strong>Creativitat</strong> estimulada</li>
<li><strong>Connexió amb el ritme natural</strong> de les estacions</li>
<li><strong>Autoexpressió</strong></li>
<li><strong>Satisfacció personal</strong></li>
<li><strong>Records</strong> (cada element té història)</li>
</ul>
<h3 id="12-què-pots-fer">1.2. Què pots fer?</h3>
<ul>
<li><strong>Centres de taula</strong> (comèlies, Nadal, etc.)</li>
<li><strong>Garlandes</strong> (parets, arbres, finestres)</li>
<li><strong>Corones</strong> (porta, paret, taula)</li>
<li><strong>Murals</strong> (art de paret)</li>
<li><strong>Mòbils</strong> (penjats, infantils)</li>
<li><strong>Espelmes</strong> amb motlles naturals</li>
<li><strong>Espelmes amb essències</strong></li>
<li><strong>Terraris</strong> (petits mons dins de vidre)</li>
<li><strong>Tests amb pintura natural</strong></li>
<li><strong>Punts de llibre</strong></li>
<li><strong>Safates</strong> decorades</li>
<li><strong>Espelmes flotants</strong></li>
<li><strong>Punts decoratius</strong> (per a arbres, parets, etc.)</li>
<li><strong>Figures</strong> amb elements naturals</li>
<li><strong>Decoració nadalenca</strong> (pròpia)</li>
</ul>
<h3 id="13-estils">1.3. Estils</h3>
<p><strong>RÚSTIC</strong>:</p>
<ul>
<li>Molt fusta, pedra, palla</li>
<li>Colors terrosos</li>
<li>Sense polir, natural</li>
</ul>
<p><strong>MINIMALISTA</strong>:</p>
<ul>
<li>Pocs elements, ben triats</li>
<li>Línies netes</li>
<li>Buit com a part del disseny</li>
</ul>
<p><strong>BOHEMI</strong>:</p>
<ul>
<li>Molts elements combinats</li>
<li>Colors càlids</li>
<li>Capritx, intuïció</li>
</ul>
<p><strong>ELEGANT</strong>:</p>
<ul>
<li>Elements ben disposats</li>
<li>Colors harmonitzats</li>
<li>Detalls fins</li>
</ul>
<p><strong>NORDIC</strong>:</p>
<ul>
<li>Blanc + fusta + verd</li>
<li>Senzillesa</li>
<li>Lluminositat</li>
</ul>

<h2 id="4-projectes-per-estació">4. PROJECTES PER ESTACIÓ</h2>
<h3 id="41-tardor-setembre-desembre">4.1. TARDOR (setembre-desembre)</h3>
<h4 id="projecte-1-corona-de-tardor-amb-fulles-seques">Projecte 1: Corona de tardor amb fulles seques</h4>
<p><strong>DIFICULTAT</strong>: fàcil</p>
<p><strong>TEMPS</strong>: 1-2 h</p>
<p><strong>MATERIALS</strong>:</p>
<ul>
<li>Base d&#x27;argila o escuma floral (o entrellaça branques)</li>
<li>Fulles seques variades (auró, roure, plàtan)</li>
<li>Pinyes, glans</li>
<li>Pistola de cola</li>
<li>Llaç de tela o jute</li>
</ul>
<p><strong>PROCEDIMENT</strong>:</p>
<ol>
<li>Prepara la base (rodona, 25-30 cm diàmetre)</li>
<li>Selecciona fulles boniques</li>
<li>Enganxa-les a la base amb cola</li>
<li>Afegeix pinyes i glans</li>
<li>Llaç a la part superior per penjar</li>
<li>Opcional: ruixar amb laca per a brillantor</li>
</ol>
<h4 id="projecte-2-centre-de-taula-amb-carbasses-i-espelmes">Projecte 2: Centre de taula amb carbasses i espelmes</h4>
<p><strong>DIFICULTAT</strong>: fàcil</p>
<p><strong>TEMPS</strong>: 30 min</p>
<p><strong>MATERIALS</strong>:</p>
<ul>
<li>1 carbassa gran o 3 de petites</li>
<li>Espelmes (amb cercle de cera)</li>
<li>Fulles seques</li>
<li>Pinyes</li>
<li>Opcional: ramellets d&#x27;espígol, romaní</li>
</ul>
<p><strong>PROCEDIMENT</strong>:</p>
<ol>
<li>Col·loca carbasses com a base</li>
<li>Encen espelmes dins o sobre les carbasses</li>
<li>Decora amb fulles, pinyes</li>
<li>Afegeix aromàtiques per olor</li>
</ol>
<h4 id="projecte-3-garlanda-de-tardor">Projecte 3: Garlanda de tardor</h4>

<p><strong>TEMPS</strong>: 2-3 h</p>

</ol>
<h4 id="projecte-4-mobiliari-de-carbassa">Projecte 4: Mobiliari de carbassa</h4>

<p><strong>TEMPS</strong>: 2-4 h</p>

<h4 id="projecte-5-safata-decorativa-amb-fulles">Projecte 5: Safata decorativa amb fulles</h4>
<p><strong>DIFICULTAT</strong>: fàcil</p>
<p><strong>TEMPS</strong>: 1-2 h</p>

<h2 id="5-tècniques">5. TÈCNIQUES</h2>
<h3 id="51-assecat-de-plantes">5.1. Assecat de plantes</h3>
<p><strong>A L&#x27;AIRE</strong>:</p>
<ul>
<li>Penjar en ramets en lloc sec i fosc</li>
<li>1-3 setmanes</li>
<li>Per a flors, fulles, herbes</li>
</ul>
<p><strong>PREMSAT</strong>:</p>
<ul>
<li>Entre papers absorbents, amb pesos</li>
<li>5-10 dies</li>
<li>Per a flors planes, fulles</li>
</ul>
<p><strong>AL MICROONES</strong>:</p>
<ul>
<li>Entre papers, 30-90 segons</li>
<li>Ràpid</li>
<li>Per a flors delicades</li>
</ul>
<p><strong>AMB SILICI GEL</strong>:</p>
<ul>
<li>Cobrir amb gel de sílice en recipient hermètic</li>
<li>5-7 dies</li>
<li>Per a flors amb volum (roses, peònies)</li>
</ul>
<p><strong>AMB GLICERINA</strong>:</p>
<ul>
<li>Barrejar 1 part de glicerina + 2 parts d&#x27;aigua calenta</li>
<li>Submergir tiges 2-3 setmanes</li>
<li>Per a fulles, branques (queden suaus i flexibles)</li>
</ul>
<h3 id="52-decoupage">5.2. Decoupage</h3>
<p><strong>MATERIALS</strong>:</p>
<ul>
<li>Elements naturals (fulles, flors, pètals)</li>
<li>Cola blanca diluïda (50% cola + 50% aigua)</li>
<li>Pinzell</li>
<li>Superfície (fusta, vidre, cartró)</li>
<li>Vernís</li>
</ul>
<p><strong>PROCEDIMENT</strong>:</p>
<ol>
<li>Composar elements</li>
<li>Aplicar cola diluïda a la superfície</li>
<li>Col·locar elements</li>
<li>Aplicar capa de cola per sobre</li>
<li>Deixar assecar</li>
<li>Vernissar</li>
</ol>
